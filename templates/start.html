Sample start

Conceiva demo data is already seeded. Follow these steps on this site. Portraits are synthetic. A shared CFTR carrier blocks donor DN-240.

Local command: uv run uvicorn app.main:app --host 127.0.0.1 --port 8000. On Vercel the database is temporary and can reset to this same seed.

Couple

  1. Open the couple door and sign in as {{ demo_couple_email }} / {{ demo_couple_password }}.
  2. Accept the consent gate. It sits in front of genetic fields and scores.
  3. On History, save blood type O and Rh negative. That is the intended parent's type, not a child's. Also enter 1 prior pregnancy and 0 miscarriages. An Rh-negative parent plus an Rh-positive donor is a flag, not a block.
  4. On Carriers, add gene CFTR, zygosity heterozygous, condition Cystic fibrosis.
  5. On the clinical survey, enter ancestry Finnish and leave CMV as any. Notes stay out of the couple explanation, and are available to the counselor report.
  6. On preferences, choose ID release open and family limit 2.
  7. Open Matches. DN-100 stays a candidate. DN-240 shows a CFTR carrier conflict and is not a candidate. DN-520 is medically clear but loses rank on anonymous ID and a family limit of 1. DN-630 is Rh positive and has no panel on file.
  8. Open DN-240 and choose Explain from the record. Each sentence expands to a field. An empty panel says it is not in the record.
  9. On Matches, add DN-100 and DN-240 to the shortlist (hard stops stay selectable). Open Shortlist, then Book a counselor and take an open demo-counselor slot.

Genetic counselor

  1. Log out, then open the counselor door as {{ demo_counselor_email }} / {{ demo_counselor_password }}.
  2. Accept consent. Open Visits, then the booked couple visit.
  3. Run reports for all candidates. DN-240 cites the CFTR conflict. DN-100 cites clear medical status and any gaps from the live profile.
  4. Optional: open Availability to see seeded slots or add another future slot.

Sperm bank

  1. Log out, then open the bank door as {{ demo_bank_email }} / {{ demo_bank_password }}.
  2. Accept consent, then open Catalog.
  3. Load the sample catalog. Confirm CAT-1. The page image is ignored and the saved portrait is synthetic.
  4. The inventory lists CAT-1 beside DN-100, DN-240, DN-310, DN-410, DN-520, and DN-630. Each seeded code has a short note on the match card.
