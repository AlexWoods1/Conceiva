What it is

Decision support for couples and sperm banks comparing a couple’s carrier report with donor records you supply. One place to surface hard medical conflicts first, then preference fit — not a diagnosis and not a prediction of a child.

How a rank is built

Hard stop

A gene both profiles list as a confirmed recessive carrier blocks that donor. The conflict stays on the row.

Soft weights

ID release, family limit, CMV, and quarantine change the score. Rh is a flag, not a block.

Context only

Ancestry overlap is allele-frequency context. It does not change the rank. There is no race filter.

Physical traits such as hair, eyes, height, and BMI can narrow the list. They never change the rank.

Explain from the record

Each match can open an explanation that cites stored database fields. Missing facts are stated as not in the record. Clinical free text stays out of model context.

  • With LLM_API_KEY set, only those retrieved fields go to the model endpoint.
  • Without a key, the same fields drive a deterministic explanation from the stored record.
  • The model does not diagnose, predict appearance, or rank by race or attractiveness.
